# Show HN: AgentHub – The open-source package manager & GitHub for AI Agents

Hey Hacker News,

I’m Amit (@1nsharma), founder of 1nsharma-labs. Today I’m releasing **AgentHub** (Apache 2.0).

### The Problem
AI models are becoming commodities, but AI Agents (autonomous workflows, prompts, and tools) are scattered across fragmented blog posts and complex Python codebases. There is no open, unified registry where you can:
1. Search verified agent roles (CEO, Mobile QA, Codebase Architect, FinOps Pruner).
2. Fork an agent template in 1 click to customize its persona.
3. Run or deploy the agent with a single zero-dependency command.

### What AgentHub Does
AgentHub is the **"GitHub of AI Agents"**:
- **Verified Community Registry:** Pre-configured agents for mobile testing, architecture mapping, FinOps auditing, and company operations.
- **1-Click Agent Forking:** `agenthub fork mowglai-ceo "MyCustomCEO"` clones the manifest into a local JSON file you can customize and version with Git.
- **Zero-Dependency CLI & MCP Server:** Run directly via `npx agenthub run` or mount into Claude Desktop and Cursor.
